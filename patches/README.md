# EQ & DSP patch downloads

Download ZIPs through **Settings → Download Patches**. Read each ZIP README before use. Extractor is always listed; native patches require exact readable hashes and recheck before replacement. Firmware-specific lsec triggers and the app APK are not included.

`index.json` records target constraints, native SHA-256 signatures, ZIP SHA-256/size and the same instructions shown in the app. App source stays private.
